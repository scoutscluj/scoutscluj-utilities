# Guided activity setup and activity administrators

The user's request approves a creation wizard, central activity settings, registration navigation under Administrative and participation payments under Finance. The follow-up explicitly selects one organizer and multiple activity administrators for this iteration; no new department-specific role system is introduced.

Creation collects basic details, organizer/administrators/departments, enrolment options, the fixed agreement details, fees/payment and a final review. The API saves the activity and initial registration settings atomically. Activities may remain unpublished for later completion. Existing records retain their creator and organizer through an additive migration.

The organizer and explicitly assigned activity administrators share activity management capabilities. Existing global privileges remain in place; assignment does not change any global account role. Settings remain editable in the activity settings page. Operational pages expose settings-icon links rather than duplicate editors.
