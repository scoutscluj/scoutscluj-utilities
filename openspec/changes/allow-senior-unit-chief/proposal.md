# Allow a Seniori beneficiary to be unit chief

## Why
Seniori units may appoint one of their adult beneficiaries as chief. The current blanket Seniori restriction prevents this even when the member already assists another unit.

## What Changes
- Allow an adult Seniori beneficiary to receive a chief responsibility for a Seniori unit in their structure.
- Preserve the primary category and simultaneous helper responsibilities, including at Temerari.
- Keep age, promise date, authorization, structure and single-chief validation.
- Continue rejecting Seniori beneficiaries as leaders or chiefs of other branches.

## Impact
- Backend responsibility validation and HTTP regression coverage.
- No API or database schema changes.
