# Improve activity agreements and participant handoff

## Why
Organizers need a compact, clear agreement editor and a fast handoff workflow that verifies physical documents and receives cash without mixing cash-only amounts into card checkout.

## What changes
- Adapt available branches and unit-specific agreement activities to eligible structures/units; select only the participant unit in immutable PDF snapshots.
- Add live PDF preview beside the editor, equipment list input, optional supplementary sections and a saved verification download.
- Separate account and member-ID registration paths; hide medication details when none is declared; show prominent actionable errors.
- Add cash-only installment allocation, explicit application of a saved plan to existing registrations, and revision-safe atomic document/cash handoff.
- Resolve unambiguous legacy root units on read without modifying stored settings.

## Authorization
The user requested implementation and production deployment and explicitly confirmed own-unit PDF contents, cash remaining in balance, and cash-only payment at handoff. Google Calendar remains deferred.
