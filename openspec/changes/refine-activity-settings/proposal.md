# Compact activity settings and direct activity navigation

The user requests one participation fee field with dismissible commission advice, focused settings submenus, a top-right creation button and direct navigation from Activities to the full activity list. These follow-up instructions approve this refinement of the existing activity setup flow.

Settings are split into General, Team, Departments, Registrations, Agreement and Payment pages. Each edits the relevant options while preserving the full registration configuration and its optimistic concurrency revision. Operational settings links open the matching page; legacy settings fragments remain compatible.

The activity menu keeps activity entries but removes the redundant all-activities and public-catalog links. Public event pages remain shareable directly. Automatic calendar synchronization was explicitly deferred by the user; this change includes no calendar synchronization, credentials or migration.
