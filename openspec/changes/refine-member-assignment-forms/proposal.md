# Member placement and responsibility form corrections

The user approved making the leader promise date optional, hiding irrelevant subgroup and adult grade fields, restricting unit choices to the edited member's current structure, and displaying leaders by their responsibility units. These changes refine the existing member workflow without changing primary categories or the separate structure-transfer workflow.

The API enforces the same boundaries as the forms. Existing primary categories and imported history remain intact. Common-collective leader/helper mandates apply to ungrouped members in their unit; they do not grant access to other subunits. Verified adult age and Seniori leader ineligibility remain enforced.
