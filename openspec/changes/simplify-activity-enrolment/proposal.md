# Simplify activity enrolment and use the supplied fixed agreement

The user explicitly requested a shareable public page per activity, a clear logged-in or member-ID enrolment flow, a completed agreement download, optional payment afterwards, and eligible activities in the existing sidebar. The configurable agreement editor is put on hold in favor of the supplied Word/PDF format.

Use the supplied DOCX as an immutable format with typed activity placeholders, preserving its clauses, tables, logos and signature areas. Render filled copies through LibreOffice; snapshot the activity details in the existing immutable publication model. Keep previous publications and generated agreements intact. Expose long activity-specific text fields beside registration settings, with no global template draft prerequisite.
